Docker Installation

Step 1:
sudo apt update

Step 2:
sudo apt install apt-transport-https ca-certificates curl software-properties-common -y

Step 3:
sudo apt install docker.io -y

Step 4:
sudo systemctl start docker
sudo systemctl enable docker

Step 5:
docker --version

Step 6:
sudo docker run hello-world

Step 7:
sudo systemctl status docker

--------------------------------------------------

Step 8:
mkdir mypythonfile

Step 9:
cd mypythonfile

--------------------------------------------------

Step 10:
nano app.py

Paste inside app.py:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello Docker! Running this Python app successfully"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)

Save:
CTRL + O
ENTER
CTRL + X

--------------------------------------------------

Step 11:
nano requirements.txt

Paste inside requirements.txt:

Flask

Save:
CTRL + O
ENTER
CTRL + X

--------------------------------------------------

Step 12:
nano Dockerfile

Paste inside Dockerfile:

FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY app.py .

EXPOSE 5000

CMD ["python", "app.py"]

Save:
CTRL + O
ENTER
CTRL + X

--------------------------------------------------

Open Website:
http://localhost:5000

--------------------------------------------------

Step 13:
docker build -t myapp-image .

Step 14:
docker images

Step 15:
docker run -d -p 8000:5000 --name myapp-container myapp-image

Step 16:
docker ps

Open Website:
http://localhost:8000

--------------------------------------------------

NOTE:
If it asks to remove rebuild:

1)
docker stop myapp-container

2)
docker rm myapp-container

3)
Repeat Steps 13, 14, 15, 16

--------------------------------------------------

Docker Hub Commands

docker login
