docker --version

--------------------------------------------------

Step 9:
cd mypythonfile

--------------------------------------------------

Step 10:
sudo apt install nano -y

--------------------------------------------------

Step 11:
nano app.py


Content of app.py

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello Docker! Running this Python app successfully"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)

nano requirements.txt


Content of requirements.txt

Flask


Save:
CTRL + O
ENTER

--------------------------------------------------

Step 13:
nano Dockerfile


Content of Dockerfile

FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY app.py .

EXPOSE 5000

CMD ["python", "app.py"]

CTRL + O
ENTER
CTRL + X

--------------------------------------------------

Step 14:
docker build -t myapp-image .

--------------------------------------------------

Step 15:
docker images

--------------------------------------------------

Step 16:
docker run -d -p 8000:5000 --name myapp-container myapp-image

Step 17:
docker ps
